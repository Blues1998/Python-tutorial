# Python tutorial

Teaching material and exercises I wrote for students learning Python.

## Contents

| Path | What it is |
| --- | --- |
| `Functions/lecture1.py` | Worked examples from the lecture on functions |
| `Functions/assignment1.py` | Exercise 1 |
| `Functions/assignment2.py` | Exercise 2 |
| `Functions/assignment3.py` | Exercise 3 |
| `main.py` | Scratch file |

Each file is standalone. Run any of them with:

```bash
python Functions/lecture1.py
```

No third-party dependencies — everything here is the standard library, on
purpose, so a student can run it on a fresh Python install.
